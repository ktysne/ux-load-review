# ux-load-review

UI の記憶、判断、操作の負担に関する 8 つの UX 規則をチェックし、対象アプリの文脈に合わせて適用するためのエージェントスキルです。
Claude Code と Codex のどちらでも使えます。

利用者が情報を思い出す、候補を比較して決める、操作対象を狙う場面で、記憶、判断、操作の負担を減らせているかを点検し、足りなければ補います。
このスキルが答える問いは、「利用者が、思い出さず、計算せず、狙わずに済むか」です。

## 8 つの規則

| 番号 | 規則 | 目的 | 対象となる場面 |
|---|---|---|---|
| 01 | 思い出させずに見て選ばせる | 利用者が候補を思い出して入力せず、画面上の候補から選べるようにする | 既知の対象を探して選ぶ場面 |
| 02 | 選んだ条件を確認画面に置いておく | 選択した条件を前の画面から思い出さず、確認画面で判断できるようにする | 注文、予約、申請などの最終確認 |
| 03 | ナビゲーションの並びと位置を安定させる | 画面が変わっても、同じ場所とラベルから移動先を予測できるようにする | 複数画面をまたぐ移動や共通ナビゲーション |
| 04 | 名前と内容に合う画像をセットにする | 視覚的な手掛かりで候補の内容を見分けられるようにする | 画像で候補を見分けられる一覧や選択 |
| 05 | 選択肢を整理し、比較条件をそろえる | 候補を絞り、同じ条件で比較できるようにする | 候補が多い一覧や料金、機能の比較 |
| 06 | 必要な案内を操作する場所に置く | 操作に必要な情報を、その操作の場で確認できるようにする | ファイル選択や制約のある入力 |
| 07 | 利用者が慣れた言葉と動作に合わせる | 利用者の経験と予測に沿って、言葉と動作を選べるようにする | 操作語彙やジェスチャーを選ぶ画面 |
| 08 | 操作対象を大きく近く置き、押せる範囲を広げる | 操作対象を探して狙う時間と誤操作を減らす | クリックやタップの対象を操作する場面 |

各規則の目的、チェック観点、対象外の条件、別の表現で満たす条件、実装上の注意は [skills/ux-load-review/references/rules.md](skills/ux-load-review/references/rules.md) にあります。

## このスキルの考え方

守るのは規則とその目的であり、特定の見た目ではありません。
規則を機械的に当てはめると、候補の少ない画面に不要な検索や画像を足したり、利用者の経験に関係なく操作を押し付けたりして、かえって使いにくくなります。
そのため、このスキルは次の順で適用の可否を判断します。

1. その記憶、判断、操作の負担が実際に発生するか
2. 利用者がその負担で困るか
3. 既存のデザインシステムや UI 規約と衝突しないか
4. プライバシーと実装コストに見合うか

心理学の法則名だけを根拠に一律適用しません。
利用者の経験、作業頻度、情報量、画面の文脈を確認し、実際の画面で提案した手段がどの負担を減らすかで判定します。

判定は「満たす」「満たさない」「適用しない」「情報不足」の四つに分けます。
チェック観点どおりの表示や操作ができなくても、別の手段で目的を達成できる場合は「適用しない」にせず、その手段の有無で判定します。

読み込み中、空、失敗、権限不足、削除、完了、入力不備の状態設計は ux-state-review に譲ります。
操作後の結果を操作した場所で知らせる設計も ux-state-review の規則 08 に譲ります。
任意の案内を後回しにでき、あとから戻れる設計も ux-state-review の規則 02 に譲ります。
文字の読みやすさや画面のまとまりだけを扱う変更では使いません。

## インストール

使うエージェントのスキルディレクトリに `skills/ux-load-review` を置きます。
スキルの形式（`SKILL.md` と参照ファイル）は Claude Code と Codex で共通です。

```bash
git clone https://github.com/ktysne/ux-load-review.git
```

ユーザー共通で使う場合：

```bash
# Claude Code
cp -r ux-load-review/skills/ux-load-review ~/.claude/skills/
```

```bash
# Codex
cp -r ux-load-review/skills/ux-load-review ~/.codex/skills/
```

特定のプロジェクトだけで使う場合は、そのリポジトリの `.claude/skills/`（Claude Code）または `.codex/skills/`（Codex）にコピーします。

クローンしたリポジトリをそのまま参照したい場合は、コピーの代わりにシンボリックリンクを張っても動作します。

## 使い方

スキルは、候補の発見、条件の確認、画面間の移動、候補の視覚的な区別、選択肢の比較、操作に必要な案内、言葉と動作の解釈、クリックやタップのしやすさを含む設計で自動的に使われます。
明示的に使わせる場合は、Claude Code では `/ux-load-review` と入力し、Codex ではスキル名 `ux-load-review` を指示に含めます。

例：

- 「予約フォームの確認画面をレビューして」
- 「料金プランの比較画面を改善したい」
- 「スマートフォンのボタンとナビゲーションが操作しにくい」

レビュー結果は、規則ごとの判定表、優先して直す項目、開発者の判断を要する項目の三つに分けて報告されます。
読み込み中、空、失敗、権限不足、削除、完了、入力不備の状態設計は ux-state-review の対象です。
